## What is JDK, JRE, JVM?

**JDK**

JDK or Java Development Kit consists of everything we need to develop a Java application. Basically, including javac, javadoc,
jdb (debugger), jar and more. It contains JRE and development tools.

**JRE**

JRA or Java Runtime Environment consists of everything we need to run a JAVA application. It itself includes JVM and core libraries.

**JVM**

JVM or Java Virtual Machine is responsible for executing JAVA bytecode. It provides platform independence and is responsible
for handling memory management, garbage collection etc.


## What is bytecode?

Bytecode is a platform independent intermediate code generated by the JAVA compiler (javac) and stored in .class files.

## What does “write once, run anywhere” mean?

Bytecode is a platform independent intermediate code generated by the JAVA compiler (javac) and stored in .class files. 

This .class file can run on:
- Windows
- macOS
- Linux

as long as JVM is installed. Thus being platform independent.
